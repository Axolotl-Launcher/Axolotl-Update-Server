Axolotl Update Server
稳定 · 安全 · 简洁
Update infrastructure

让每一次更新，
都安静抵达。

Axolotl Update Server 为 Launcher 提供可靠的版本检测、签名安装包分发，以及 Release / Beta 更新通道。

版本清晰

基于 SemVer 选择匹配版本，让稳定版与 Beta 版本各自保持明确节奏。

文件可信

服务端校验 SHA-256、大小与签名，确保客户端拿到完整且可验证的安装包。

部署轻量

动态 API 运行在 Flask，静态文件交给 Caddy 高效分发，简单可靠。

GET   /latest   →   检查最新更新
GET   /dist/<version>/...  →   获取发布文件
