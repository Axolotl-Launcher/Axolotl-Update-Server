## 百万条写入测量

命令：

```sh
TEST_POSTGRES_URL='<测试管理员连接串>' go test ./internal/analytics -run '^$' -bench BenchmarkBatchWrite -benchtime=2000x -count=1
```

样例为 2000 批 × 500 条，10 种重复 UA，固定 IPv4、`/latest` 路由和少量渠道/版本/平台字段。数据库执行真实事务和索引写入；计时不包含创建数据库、迁移及分区初始化。

| 指标 | 本机实测 |
| --- | --- |
| 每批 500 条平均耗时 | 约 7.68 ms |
| 写入吞吐 | 约 65,103 条/秒 |
| `pg_database_size` / 记录数 | 约 156.8 字节/条 |

容量指标包含新测试数据库的基础占用、表和索引，不包含 PostgreSQL WAL、备份或应用日志。UA/IP/版本分布变化会改变占用，不能作为生产承诺。以此样例估算，每天百万条、14 天约 2.2 GB 数据库占用，仍需为 WAL、备份和运维留余量。5～10 GB 不作为硬限制。
